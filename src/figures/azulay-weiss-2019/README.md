Adaptation: Poppler vector export, removal of every raster image element and its references, then a viewBox excerpt. No chart values are inferred or redrawn. The original graph typography is preserved. The files may retain unused off-viewBox vector definitions; they contain no raster photograph data. Figure 9 shows middle/bottom sensitivity panels only. Figure 3 and Figure 7 are not included as images. The captions in the reading retain the original complete-figure descriptions, so use each image's scope notice.

`manifest.json` records the page, PDF-point crop rectangle, panel scope and LF-normalized asset hash/length. `scripts/reading-assets.mjs` checks integrity and disallows raster data, scripts and external references before publishing. `scripts/extract-reading-figures.mjs` is an optional editorial regeneration helper; normal builds do not need Poppler or the source PDF. A successful extraction is not proof of correct cropping or permission: compare axes, legends, points and caption scope with the actual source pages.
